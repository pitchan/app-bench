2. Catalog and business rules

2.1 Glossary

Term Definition
Bike configuration The choices of one bike: frame, wheels, drivetrain, color and the set of selected accessories. The rider height and the quantity are not part of it.
Configurator The part of the page where the customer builds the current bike: height, option cards, quantity.
Current bike The bike configuration shown in the configurator, with its quantity.
Order line One bike configuration with a quantity, added to the order (05-fr-order-lines).
Order The list of order lines, at most four, and the applied promo code.
Bikes in the order The sum of the quantities of all order lines, written B.
Valid height A height that satisfies FR-FIT-01.
Recommended frame The frame given by section 2.4 for a valid height.
Automatic frame mode The state in which the frame follows the recommended frame (FR-FIT-03).
Automatic frame change A change of the selected frame to a different frame, made by automatic frame mode (FR-FIT-03). A height change after which the selected frame is the same as before is not an automatic frame change: no cascade is applied and notice keeps its text.
User action One click or keyboard selection by the customer on an option card or a quantity button of the configurator. Typing in the height field is not a user action in this sense.
Cascade A change made by the system to another option as a consequence of a user action or of an automatic frame change (section 2.3).
Cents An amount expressed as an integer number of euro cents. €12.50 is 1250 cents.
Today, now The browser's current local date, and current local date and time.

2.3 Compatibility rules

Unavailable options

An unavailable option cannot be selected: its input is disabled.

Option Unavailable while Reason
29" wheels the frame is S MSG-04
Pro Electronic 2×12 the frame is S MSG-04
Glacier the frame is S or XL MSG-05

While no frame is selected, every option is available.

Constraints

A bike configuration shall always satisfy all of these constraints:

  1. Frame S is not combined with 29" wheels, nor with Pro Electronic 2×12.
  2. Glacier is combined only with frame M, frame L or no frame.
  3. Pro Electronic 2×12 is combined only with 29" wheels.
  4. Rear rack is combined only with Mudguards.
  5. Rear rack and Kickstand are never both selected.

Cascades

After a user action or an automatic frame change, the system applies every cascade of this table whose condition holds, in the order of the table, each one on the result of the previous ones. Each applied cascade adds its message to the notice (FR-OPT-05).

# Trigger Condition Change Message
C1 frame S becomes selected 29" wheels selected select 27.5" wheels MSG-06
C2 frame S becomes selected Pro Electronic 2×12 selected select Sport 1×12 MSG-07
C3 frame S or XL becomes selected Glacier selected select Graphite MSG-08
C4 the user selects Pro Electronic 2×12 27.5" wheels selected select 29" wheels MSG-09
C5 the user selects 27.5" wheels Pro Electronic 2×12 selected select Sport 1×12 MSG-10
C6 the user checks Rear rack Mudguards not checked check Mudguards MSG-11
C7 the user checks Rear rack Kickstand checked uncheck Kickstand MSG-12
C8 the user unchecks Mudguards Rear rack checked uncheck Rear rack MSG-13
C9 the user checks Kickstand Rear rack checked uncheck Rear rack MSG-14

A cascade never triggers another cascade: the triggers name user actions and frame changes only, and the table covers every combination.

2.4 Frame recommendation

For a valid height h, the recommended frame is the frame whose rider height range contains h. The ranges are inclusive at both ends and cover 150 to 200 without gap.

2.5 Price calculation

All amounts are integer cents. Rounding uses round half up: a non-negative exact value x is rounded to the integer ⌊x + ½⌋. Percentages are computed on exact values, then rounded once. Floating-point arithmetic shall not be used for money.

Unit price of a bike configuration

frame price + wheels surcharge + drivetrain surcharge + color surcharge (with the red rule of 2.2) + sum of the prices of the selected accessories.

Order amounts

For an order with at least one line:

Step Name Formula
1 Line amount for each line: unit price × line quantity
2 Commuter pack for each line whose accessories include Mudguards, Rear rack and Lights: 3000 × line quantity; otherwise 0
3 Bikes amount sum over the lines of (line amount − commuter pack)
4 Volume discount B from 3 to 5: round half up of (bikes amount × 5 / 100); B of 6 or more: round half up of (bikes amount × 8 / 100); otherwise 0
5 Team discount while TEAM15 is applied and active: round half up of (sum over the performance lines of (line amount − commuter pack) × 15 / 100); otherwise 0
6 Discount choice while the team discount is greater than the volume discount, the team discount is used and the volume discount is not; otherwise the volume discount is used and the team discount is not
7 After volume discount bikes amount − the volume discount used
8 Promo discount SPRING10 applied and active: round half up of (after volume discount × 10 / 100). WELCOME50 applied and active: 5000. TEAM15: the team discount used. Otherwise 0.
9 Merchandise after volume discount − promo discount
10 Shipping 0 if FREESHIP is the applied code, or if merchandise ≥ 500000; otherwise 4900 + 1500 × (B − 1)
11 Total merchandise + shipping
12 VAT included round half up of (total × 20 / 120)

"The volume discount used" is 0 when step 6 uses the team discount. For SPRING10, "active" is evaluated on the after volume discount amount of step 7. The VAT included is informative: it is part of the total, not added to it.

2.6 Delivery calculation

  1. Line lead time = the line's drivetrain lead time, plus 3 if its color is red, plus 2 if its quantity is 3 or more.
  2. Order lead time = the largest line lead time, plus 1 for each line beyond the first, plus 1 if now is 14:00 or later.
  3. Delivery date: starting from the day after today, count business days one by one; the delivery date is the business day whose count equals the order lead time. Today itself is never counted, whatever day it is.

Bike description

The bike description of a bike configuration is the accessible names of its frame, wheels, drivetrain and color, in that order, separated by · (a space, U+00B7 MIDDLE DOT, a space).

Example: Frame L · 29" wheels · Sport 1×12 · Racing Red.

The accessory list is the accessible names of the selected accessories in catalog order, separated by , (a comma and a space), or No accessories when none is selected.
