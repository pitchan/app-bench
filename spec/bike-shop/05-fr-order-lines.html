5. Functional requirements — Order lines

FR-LIN-01 Add to order

  • Statement: While no line is being edited and the height is not valid, the system shall disable add-to-order and show add-hint with MSG-03. While no line is being edited, the height is valid and no frame is selected, the system shall disable add-to-order, and add-hint shall not be visible. When the user activates the enabled add-to-order while no line is being edited, the system shall add the current bike configuration with its quantity to the order as a new last line, unless FR-LIN-02 merges it or FR-LIN-04 refuses it, and then reset the configurator: the options and quantity of FR-OPT-01, automatic frame mode on (so that the recommended frame of the height is selected), the height field unchanged, the undo history empty, notice hidden.
  • Rationale: The customer adds bikes one after another, each starting from the defaults, for the same or another rider.
  • Verification: Test
  • Acceptance criteria:
Scenario: Adding a bike resets the configurator
  When the user fills height-input with "180"
  And the user selects card-color-red
  And the user clicks add-to-order
  Then order-line-1 is visible
  And the description of order-line-1 reads "Frame L · 27.5\" wheels · Essential 1×10 · Racing Red"
  And the radio "Graphite" is checked
  And the radio "Frame L" is checked
  And height-input has the value "180"

FR-LIN-02 Merging identical bikes

  • Statement: When a bike is added and the order already holds a line with the same bike configuration (same frame, wheels, drivetrain, color and set of accessories), the system shall add the quantity to that line instead of creating a new line, keeping the line's position.
  • Rationale: One line per distinct bike keeps the order readable.
  • Verification: Test
  • Acceptance criteria:
Scenario: Same bike twice
  When the user adds a bike "Frame M, quantity 2"
  And the user adds a bike "Frame L"
  And the user adds a bike "Frame M"
  Then the qty of order-line-1 reads "3"
  And order-line-3 is not visible

FR-LIN-03 Order line content

  • Statement: The system shall show one order-line-<n> per order line, numbered from 1 in the order of the lines, each with the bike description, the accessory list, the quantity and the line amount of 02-catalog-and-rules, sections 2.5 and 2.7, and its Edit and Remove buttons. While the order has no line, the system shall show order-empty with MSG-19.
  • Rationale: Each bike of the order can be checked and acted on.
  • Verification: Test
  • Acceptance criteria:
Scenario: Line with accessories
  When the user adds a bike "Frame M, Sport 1×12, Lights, Mudguards, quantity 2"
  Then the accessories of order-line-1 read "Mudguards, Lights"
  And the qty of order-line-1 reads "2"
  And the amount of order-line-1 reads "€3,029.80"
  And order-empty is not visible

FR-LIN-04 Line limits

  • Statement: If adding or saving a bike would make a line hold more than 5 bikes, then the system shall change nothing in the order and show line-error with MSG-16. Otherwise, if it would make the order hold more than 4 lines, then the system shall change nothing in the order and show line-error with MSG-17. Otherwise, if it would make B greater than 10, then the system shall change nothing in the order and show line-error with MSG-18. A refused add or save shall leave the configurator unchanged. line-error shall be hidden at the next user action, at the next successful add or save, at a cancelled edit and when a line is removed.
  • Rationale: The workshop builds at most five identical bikes, four different bikes and ten bikes per order.
  • Verification: Test
  • Acceptance criteria:
Scenario: Fifth line refused
  Given the order holds four lines with different bikes
  When the user adds a bike "Frame XL, Kickstand"
  Then line-error reads "An order cannot hold more than 4 lines."
  And order-line-5 is not visible
  And the checkbox "Kickstand" is checked

FR-LIN-05 Editing a line

  • Statement: When the user activates the Edit button of a line, the system shall load that line's bike configuration and quantity into the configurator, turn automatic frame mode off, empty the undo history, hide notice, show cancel-edit, show in add-to-order the text Update line {n} for that line, disable place-order and show place-hint with MSG-31. The height field shall stay unchanged. While a line is being edited, the Edit button of another line shall load that other line instead, as if the first edit had been cancelled.
  • Rationale: A bike already in the order can be changed without rebuilding it.
  • Verification: Test
  • Acceptance criteria:
Scenario: Editing loads the line
  When the user adds a bike "Frame XL, Pro Electronic 2×12, quantity 2"
  And the user clicks the Edit button of order-line-1
  Then the radio "Pro Electronic 2×12" is checked
  And the radio "29\" wheels" is checked
  And qty-value reads "2"
  And add-to-order reads "Update line 1"
  And place-order is disabled

FR-LIN-06 Saving an edited line

  • Statement: When the user activates add-to-order while a line is being edited, the system shall replace that line's bike configuration and quantity with those of the current bike, keeping its position, then end the edit and reset the configurator as in FR-LIN-01. If the new bike configuration equals that of another line, the system shall instead add the quantity to the line with the smaller number and remove the other one, the following lines being renumbered. FR-LIN-04 applies to the result. The height field need not be valid to save an edit.
  • Rationale: An edit changes one bike and never leaves two identical lines.
  • Verification: Test
  • Acceptance criteria:
Scenario: Edit that makes two lines identical
  When the user adds a bike "Frame M"
  And the user adds a bike "Frame L"
  And the user clicks the Edit button of order-line-2
  And the user selects card-frame-M
  And the user clicks add-to-order
  Then the qty of order-line-1 reads "2"
  And order-line-2 is not visible

FR-LIN-07 Cancelling an edit

  • Statement: When the user activates cancel-edit, the system shall leave the order unchanged, end the edit, hide cancel-edit and place-hint, and reset the configurator as in FR-LIN-01.
  • Rationale: An edit can be abandoned without effect.
  • Verification: Test
  • Acceptance criteria:
Scenario: Cancel keeps the line
  When the user adds a bike "Frame L, Racing Red"
  And the user clicks the Edit button of order-line-1
  And the user selects card-color-sand
  And the user clicks cancel-edit
  Then the description of order-line-1 reads "Frame L · 27.5\" wheels · Essential 1×10 · Racing Red"
  And add-to-order reads "Add to order"

FR-LIN-08 Removing a line

  • Statement: When the user activates the Remove button of a line, the system shall remove it from the order and renumber the following lines. If that line was being edited, the edit shall end and the configurator shall be reset as in FR-LIN-01; if another line was being edited, that edit shall continue with its line's new number.
  • Rationale: A bike can be taken out of the order at any time.
  • Verification: Test
  • Acceptance criteria:
Scenario: Remove the first of two lines
  When the user adds a bike "Frame M"
  And the user adds a bike "Frame XL"
  And the user clicks the Remove button of order-line-1
  Then the description of order-line-1 reads "Frame XL · 27.5\" wheels · Essential 1×10 · Graphite"
  And order-line-2 is not visible
