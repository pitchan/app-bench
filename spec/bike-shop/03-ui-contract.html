3. User interface contract

3.1 Page structure

app-header                      brand title (see 01-product-overview, 1.6)
main
├── configurator
│   ├── section-rider           height field, error, recommendation
│   ├── section-frame           frame cards
│   ├── section-wheels          wheels cards
│   ├── section-drivetrain      drivetrain cards
│   ├── section-color           color cards
│   ├── section-accessories     accessory cards
│   ├── section-quantity        quantity buttons and value
│   └── bike-price, undo-button, add-to-order, add-hint, cancel-edit, line-error
└── order
    ├── order-empty
    ├── order-line-1 … order-line-4

    ├── summary lines
    └── place-order, place-hint
notice                          live message of the last cascades
confirmation                    shown instead of main after an order

The elements are listed in reading order. Placement, sizes and styles are free (08-rendering sets the limits).

3.2 Element identifiers

Each element below shall carry the attribute data-testid with exactly the given value, unique in the page.

Presence:

  • Permanent: present and visible while main is shown (not during the confirmation).
  • Conditional: visible only in the situation the requirements describe; otherwise absent or not visible.

"Visible" and "not visible" have the meanings of README, section 2.5.

Structure

Option cards

One card per option of section 2.2 of the catalog, with data-testid card-<group>-<option id>, where <group> is frame, wheels, drivetrain, color or accessory. Each section holds the cards of its group in catalog order.

Examples: card-frame-XL, card-wheels-275, card-drivetrain-pro, card-color-glacier, card-accessory-rack.

Each card is a <label> element that contains:

Inside the card Element Content Presence
the input <input type="radio"> for frame, wheels, drivetrain, color; <input type="checkbox"> for accessories. Radios of one group share one name. Accessible name exactly the catalog accessible name, e.g. Frame M Permanent
[data-role="name"] any The catalog accessible name Permanent
[data-role="price"] any FR-OPT-02 Permanent
[data-role="reason"] any MSG-04 or MSG-05 Conditional: visible only while the option is unavailable
[data-role="badge"] any, frame cards only Text Recommended Conditional: FR-FIT-02

The input may be visually hidden; it shall stay focusable and operable with the keyboard. A selected card and an unavailable card shall look different from the other cards; how is free.
