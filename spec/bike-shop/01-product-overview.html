1. Product overview

1.1 Purpose

Atelier Order Desk lets a customer order several made-to-measure bicycles on one page. For each bike, the customer enters the rider's height, chooses a frame size, wheels, drivetrain, color and accessories, and adds the bike to the order. The order can hold several different bikes; each can be edited or removed. The page shows the order amounts and the delivery date as soon as anything changes, and places the order.

1.2 Scope

In scope:

  • Rider height and frame size recommendation.
  • Option choices with compatibility rules and automatic adjustments, with an undo history.
  • An order of up to four lines, each line being one bike configuration with a quantity.
  • Order amounts with a commuter pack discount, a volume discount, one promo code, shipping and VAT.
  • An estimated delivery date counted in workshop business days, with an afternoon cut-off.
  • An order confirmation shown on the page.

Out of scope:

  • Payment, accounts, addresses, servers, e-mails.
  • Persistence: a reload starts a new order.
  • Currencies other than the euro. Every price includes VAT.
  • Any control not described in this specification.

1.3 User

One customer, on a desktop or a phone browser, using mouse, touch or keyboard.

1.4 Operating environment

  • A current version of Chromium.
  • The page is opened directly from the file system or from any static file server.
  • "Today" and "now" are the browser's current local date and time.
  • Viewport widths from 360 px to 1920 px.

1.5 Design and implementation constraints

  • One file named index.html. All HTML, CSS, JavaScript and SVG are inline. See NFR-PKG-01.
  • No library, framework, font or image loaded from the network. See NFR-NET-01.
  • No alert, confirm or prompt. See NFR-DLG-01.
  • No uncaught script error. See NFR-ERR-01.
  • The data-testid values, accessible names and texts of 03-ui-contract are part of the interface and shall be used exactly as written.
  • The visual design is free within 08-rendering.

1.6 Assumptions

  • The page title and the page's visible brand title are set by the instructions that accompany this specification, not by this document.
