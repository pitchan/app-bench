7. Functional requirements — Checkout

FR-CHK-01 Place order button

  • Statement: The system shall show in place-order the text MSG-27 for the current number of bikes in the order. While the order has no line or a line is being edited, the system shall disable place-order; while a line is being edited, it shall also show place-hint with MSG-31.
  • Rationale: An order is placed only with bikes in it and no change pending.
  • Verification: Test
  • Acceptance criteria:
Scenario: Label follows the number of bikes
  When the page loads
  Then place-order reads "Place order"
  And place-order is disabled
  When the user adds a bike "Frame M, quantity 3"
  Then place-order reads "Place order (3 bikes)"
  And place-order is enabled

FR-CHK-02 Confirmation

  • Statement: When the user activates the enabled place-order, the system shall hide main and notice, and show confirmation with confirmation-title (MSG-28), confirmation-reference (MSG-29), confirmation-bikes (MSG-30), confirmation-total (the order total, amount format), confirmation-delivery (the delivery date, date format) and confirmation-new. The values shall be those of the order at the moment it was placed.
  • Rationale: The customer gets a clear record of the placed order.
  • Verification: Test
  • Acceptance criteria:
Scenario: Confirmation of a single bike
  When the user adds a bike "Frame M"
  And the user clicks place-order
  Then confirmation-title reads "Order confirmed"
  And confirmation-bikes reads "1 bike"
  And confirmation-total reads "€1,239.00"
  And configurator is not visible

FR-CHK-03 Order reference

  • Statement: The system shall number placed orders from 1 when the page loads and add 1 at each placed order, and shall build confirmation-reference with MSG-29 from today and that number. A reload starts again at 1.
  • Rationale: Each order placed in one visit has its own reference.
  • Verification: Test
  • Acceptance criteria:
Scenario: Second order of the visit
  Given now is 2026-11-20 09:30
  When the user places an order
  And the user clicks confirmation-new
  And the user places an order
  Then confirmation-reference reads "AT-20261120-002"

"The user places an order" means: the user adds a bike "Frame M" and clicks place-order.

FR-CHK-04 New order

  • Statement: When the user activates confirmation-new, the system shall hide confirmation, show main, empty the order, remove the applied code, empty height-input and promo-input, hide every error, and reset the configurator.
  • Rationale: The next order starts from scratch, with only the order number kept.
  • Verification: Test
  • Acceptance criteria:
Scenario: Back to an empty order
  When the user applies "FREESHIP"
  And the user places an order
  And the user clicks confirmation-new
  Then order-empty is visible
  And promo-status is not visible
  And height-input has the value ""
  And no frame radio is checked
