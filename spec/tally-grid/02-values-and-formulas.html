2. Values and formulas

This file defines the rules. The requirements of files 04 to 07 refer to them.

2.1 Glossary

Term Definition
Grid 8 columns named A to H, left to right, and 12 rows numbered 1 to 12, top to bottom.
Address A column letter followed by a row number, in capitals: A1, H12.
Cell One position of the grid. It holds a raw content and a format.
Raw content The string stored in the cell (section 2.2). The empty string for an empty cell.
Empty cell A cell whose raw content is the empty string.
Value What the raw content evaluates to: a number, a text, a logical value, an error or blank (section 2.3).
Format One of general, fixed2, percent1 (section 2.5). general on a new sheet.
Anchor, active cell Two cells, possibly the same. They define the selection.
Selection The rectangle of cells whose two opposite corners are the anchor and the active cell. Its top-left cell is the cell of its first row and first column.
Visiting order The order of the cells of a rectangle: row by row from the top, and inside a row from left to right.
Formula A raw content that starts with =.
Valid formula A formula that follows the syntax of section 2.6.

2.2 Entered content

When a string s is committed to a cell (FR-EDT-03), the kind of content is decided by the first rule that applies, in this order:

# Condition on s Kind Raw content Value
1 s is the empty string empty empty string blank
2 s starts with = formula the canonical form of s when the formula is valid (section 2.6.4); otherwise s unchanged the result of the formula; #SYNTAX! when the formula is not valid
3 s starts with ' (U+0027) text s unchanged the text s without its first character (possibly the empty text)
4 s, without its leading and trailing spaces, is an entry number number s unchanged that number
5 s, without its leading and trailing spaces, is TRUE or FALSE in any letter case logical s unchanged that logical value
6 otherwise text s unchanged the text s, spaces included

Entry number. A string that matches ^[+-]?(\d+(\.\d+)?|\.\d+)%?$ and whose number is below 10^15 in absolute value once normalized (section 2.4). The number is the decimal number written, divided by 100 when the string ends with %, then normalized. 12, -0.5, +3, .25, 007 and 12.5% are entry numbers. 1., 1e3, 1,000, 12 % and 1000000000000000 are not: they are texts.

"Spaces" are U+0020 characters only.

Error values, with the text they are shown as:

Error Cause

Value of a formula cell. The value of a cell that holds a valid formula is the result of its expression, with one exception: when the expression evaluates to blank, the value of the cell is the number 0.

2.4 Number normalization

Every number of the sheet is normalized: rounded to 12 significant digits, ties rounded away from zero. For a number x this is the JavaScript expression Number(x.toPrecision(12)). Negative zero is replaced by 0. The normalized number is written N(x).

Normalization applies to:

  • every entry number (section 2.2);
  • every number literal of a formula;
  • the result of every arithmetic operator (+, -, *, /, ^, unary -, unary +, %);
  • the result of every function that returns a number.

Inside one operator or one function, the computation is made with JavaScript numbers (IEEE 754 double precision) on the normalized operands, and only its result is normalized.

Range of numbers. If the result of an operator or of a function is not a finite number, or if its normalized absolute value is 10^15 or more, the result is the error #NUM!. A number literal of a formula in that case gives #NUM! as well.

Examples: =0.1+0.2 is 0.3. =1/3 is 0.333333333333. The value of =1/3*3 is 0.999999999999 (the division is normalized before the multiplication); a general cell shows it as 1. =123456789012345+0 is 123456789012000.

Decimal representation. The decimal representation D(x) of a normalized number x is its exact writing with 12 significant digits, in plain decimal notation without exponent: Number.prototype.toPrecision(12) expanded to plain notation. Examples: D(1.005) is 1.00500000000, D(0.1) is 0.100000000000, D(-1250) is -1250.00000000.

Decimal rounding. R(x, d), for an integer d, is x rounded to d decimal places, computed on the digits of D(x), ties rounded away from zero. A negative d rounds to the left of the decimal point. Examples: R(1.005, 2) = 1.01, R(2.675, 2) = 2.68, R(-2.5, 0) = -3, R(1250, -2) = 1300, R(1.0000005, 6) = 1.000001, R(0.0000004, 6) = 0.

Rounding the binary value of the number instead (for example with toFixed or Math.round(x * 100) / 100) gives other results on such ties and does not conform.

2.5 Display

The text shown in a cell depends on its value and, for a number, on the format of the cell.

Value Text shown
blank (empty cell) nothing
text the text, unchanged
logical TRUE or FALSE
error the error text, for example #DIV/0!
number according to the format, below

Number formats, for a number x:

Format Text shown Examples
general R(x, 6) written in plain decimal notation, without trailing zeros in the decimal part, and without decimal point when no decimal remains. 12, -0.5, 0.333333, 1.000001, 123456789012000
fixed2 R(x, 2) written with exactly two decimals, the integer part grouped by three digits with ,. 1,234.50, -1,234,567.00, 0.13
percent1 R(N(x × 100), 1) written with exactly one decimal and no grouping, followed by %. 12.5%, -0.3%, 1250.0%

In the three formats: a negative result starts with - (U+002D); a result that rounds to zero is written without sign (0, 0.00, 0.0%); there is no exponent and no space.

The format has no effect on values that are not numbers.

General text of a number. G(x) is the text of x in the general format, whatever the format of any cell. It is used when a number becomes a text inside a formula (section 2.7.3).

2.6 Formula language

2.6.1 Tokens

After the leading =, a formula is a sequence of tokens. Spaces between tokens are ignored; spaces inside a string literal belong to it. Any other character that starts none of the tokens below makes the formula not valid.

Token Definition
number literal \d+(\.\d+)? or \.\d+, the longest match. No sign, no exponent. 1. is the number 1 followed by the character ., which makes the formula not valid.
string literal Starts and ends with ". Inside, "" stands for one ". A string literal that is not closed makes the formula not valid.
word A longest run of letters A–Z, a–z, digits and $ that starts with a letter or $. Classified below.
#REF! These five characters, in any letter case.
operators + - * / ^ & % = <> <= >= < > (the longest match)
punctuation ( ) , :

A word is classified by the first rule that applies:

# Word Token
1 TRUE or FALSE, in any letter case logical literal
2 matches ^\$?[A-Za-z]+\$?[0-9]+$ reference
3 letters and digits only (no $) name
4 anything else (for example A$, $$A1, $A) the formula is not valid

A reference has a column part and a row part, each with or without a leading $: B7, $B7, B$7, $B$7. The letter case is ignored. A reference is inside the grid when its column is A to H and its row is 1 to 12; otherwise it is outside the grid (I1, AA3, A0, A13, B007 is B7 and inside the grid).

2.6.2 Grammar

formula    := "=" expression
expression := comparison
comparison := concat   { ( "=" | "<>" | "<" | "<=" | ">" | ">=" ) concat }
concat     := sum      { "&" sum }
sum        := product  { ( "+" | "-" ) product }
product    := signed   { ( "*" | "/" ) signed }
signed     := ( "-" | "+" ) signed | power
power      := percent  [ "^" signed ]
percent    := primary  { "%" }
primary    := number | string | logical | "#REF!" | range | reference | call | name
            | "(" expression ")"
range      := reference ":" reference
call       := name "(" [ expression { "," expression } ] ")"

{ x } means zero or more times, [ x ] zero or one time. A formula is valid when the whole text after = is one expression. = alone is not valid.

Consequences that the implementation shall respect:

  • comparison, concat, sum and product are left-associative: =10-4-3 is 3, =1<2<3 is (1<2)<3.
  • ^ is right-associative and binds tighter than the unary signs on its left: =2^3^2 is 2^(3^2) = 512, =-2^2 is -(2^2) = -4, =2^-2 is 0.25.
  • % applies to the primary on its left and may be repeated: =50% is 0.5, =-5% is -(5%), =2^3% is 2^0.03, =5%% is 0.0005.
  • A name followed by ( is a call. A name that is not followed by ( is a valid primary whose value is #NAME?.
  • A reference or a logical literal followed by ( is not valid.
  • A call may have no argument: =SUM() is valid (its value is #ARGS!). An empty argument, as in =SUM(1,,2), is not valid.

2.6.3 Functions

25 functions exist: SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, ROUND, ABS, INT, MOD, IF, AND, OR, NOT, IFERROR, ISERROR, ISBLANK, LEN, UPPER, LEFT, RIGHT, MID, CONCAT, COUNTIF, SUMIF. Their names are recognized in any letter case. Section 2.8 defines them.

2.6.4 Canonical form

The canonical form of a valid formula is = followed by its tokens, in order, with no space between them, each token written as follows:

Token Written as
number literal as typed (1.50 stays 1.50, .5 stays .5)
string literal as typed, quotes included
logical literal, name, #REF! in capitals
reference outside a range in capitals, $ signs kept
range normalized: the top-left corner, :, the bottom-right corner, in capitals. Each $ sign stays with the column part or the row part it was typed on. =sum(b3:a1) gives =SUM(A1:B3); $b3:a$1 gives A$1:$B3; c2:c2 stays C2:C2. Columns are ordered A < … < Z < AA < …; rows by number. When the two references have the same column, their column parts keep the order typed; when they have the same row, their row parts keep the order typed ($b$2:b1 gives $B1:B$2).
operators, punctuation as typed

Row numbers are written without leading zeros (b007 gives B7).

Example: = if( a1 >= 10 , "big" , sum( $b$2:b1 ) ) gives =IF(A1>=10,"big",SUM($B1:B$2)).

2.7 Evaluation

2.7.1 Primaries

Primary Value
number literal the normalized number, or #NUM! (section 2.4)
string literal the text
logical literal the logical value
#REF! the error #REF!
reference inside the grid the value of that cell; blank when the cell is empty
reference outside the grid #REF!
name not followed by ( #NAME?
range, anywhere but as a range argument of a function (section 2.8.1) #VALUE!

2.7.2 Errors first

An operator evaluates its left operand, then its right operand. If the left operand is an error, the result is that error. Otherwise, if the right operand is an error, the result is that error. This is checked before any type rule below. The rules for function arguments are in section 2.8.

2.7.3 Conversions

Conversion number logical blank text
to number itself TRUE → 1, FALSE → 0 0 #VALUE! (always, even when the text looks like a number)
to text G(x) TRUE or FALSE the empty text itself
to logical 0 → FALSE, any other → TRUE itself FALSE #VALUE!
to integer to number, then truncated toward zero

When both operands of an operator fail their conversion, the error of the left operand is the result.

2.7.4 Arithmetic

+, -, *, /, ^, unary -, unary + and % convert their operands to number.

Operator Result
a + b, a - b, a * b N of the sum, difference, product
a / b #DIV/0! when b is 0; otherwise N(a / b)
a ^ b #NUM! when a is 0 and b is 0; #DIV/0! when a is 0 and b is negative; #NUM! when a is negative and b is not an integer; otherwise N(a^b) (Math.pow)
-a, +a N(-a), N(a)
a% N(a / 100)

The range rule of section 2.4 applies to every result.

2.7.5 Concatenation

a & b converts both operands to text and gives the text made of a followed by b.

2.7.6 Comparison

=, <>, <, <=, >, >= give a logical value.

  1. A blank operand is first replaced, according to the other operand: by the number 0 when the other is a number or is blank too; by the empty text when the other is a text; by FALSE when the other is a logical value.
  2. Operands of the same type are compared:
    • numbers: by value;
    • texts: after converting both to capitals (JavaScript toUpperCase()), UTF-16 code unit by code unit; a text that is a prefix of another comes first;
    • logical values: FALSE is less than TRUE.
  3. Operands of different types: any number is less than any text, and any text is less than any logical value. They are never equal.

2.8 Functions

2.8.1 Arguments

  • An argument is a range argument when it consists of exactly one reference, exactly one range or exactly the #REF! token, with nothing else: no parentheses, no operator. A single reference is a range of one cell. Any other argument is a value argument: it is evaluated as an expression.
  • Only the functions and argument positions marked "range" in section 2.8.3 treat a range argument as a range. Everywhere else, the argument is evaluated as an expression: a reference gives the value of its cell and a range gives #VALUE! (section 2.7.1).
  • A range argument used as a range gives the error #REF! when it is the #REF! token or when one of its corners is outside the grid. Otherwise its cells are taken in visiting order (section 2.1).

2.8.2 Order of checks in a call

  1. The name is not one of the 25 functions: #NAME?. No argument is evaluated.
  2. The number of arguments is not allowed for the function: #ARGS!. No argument is evaluated.
  3. The arguments are processed in order, from the first to the last, as section 2.8.3 states for the function. The first error met is the result, unless the function states otherwise (IF, IFERROR, ISERROR). A cell of a range whose value is an error is "an error met" when that cell is visited.

2.8.3 Definitions

The number of arguments allowed is the number of parameters of the signature shown; … after a parameter means that one or more arguments are allowed.

"Number", "text", "logical", "integer" mean: the argument is evaluated as an expression and converted with section 2.7.3; an error value or a failed conversion is the result of the function. Results that are numbers are normalized and follow the range rule of section 2.4.

Aggregates. SUM, AVERAGE, MIN, MAX, COUNT, COUNTA take one argument or more. Each argument is a range (when it is a range argument) or a value.

Function Range argument Value argument Result
SUM each number cell contributes; text, logical and empty cells are ignored converted to number, contributes the contributions added in order, starting from 0
AVERAGE as SUM as SUM the sum divided by the number of contributions; #DIV/0! when there is none
MIN, MAX as SUM as SUM the smallest, the largest contribution; 0 when there is none
COUNT each number cell counts 1 counts 1 when its value is a number, 0 otherwise the count
COUNTA each cell that is not empty counts 1 counts 1 the count

A "number cell" is a cell whose value is a number; so a formula cell whose result is a number is a number cell, and a formula cell whose expression is blank is a number cell of value 0 (section 2.3). In a range, an error cell is an error met (section 2.8.2). A value argument that is an error is an error met, for the six functions.

Numbers.

Function Arguments Result
ROUND(x, d) number, integer #NUM! when d is below -9 or above 9; otherwise N(R(x, d))
ABS(x) number the absolute value
INT(x) number the largest integer less than or equal to x (INT(-2.5) is -3)
MOD(a, b) number, number #DIV/0! when b is 0; otherwise N(a - b × floor(a / b)), where a / b is not normalized (MOD(-7, 3) is 2, MOD(7, -3) is -2)

Logic.

Function Arguments Result
IF(c, a, b) exactly three c is converted to logical (an error or a failed conversion is the result). When TRUE the result is the value of a, otherwise the value of b. Only the chosen one of a and b is evaluated; the result may be blank.
AND(a, …), OR(a, …) one or more Every argument is evaluated and converted to logical, in order; the first error is the result. Otherwise AND is TRUE when all are TRUE, OR is TRUE when one at least is TRUE.
NOT(a) logical the opposite logical value
IFERROR(x, y) exactly two x is evaluated. When it is an error, the result is the value of y (which may be an error); otherwise the result is the value of x and y is not evaluated.
ISERROR(x) exactly one TRUE when x evaluates to an error, otherwise FALSE. Never an error.
ISBLANK(x) exactly one, range When the argument is a range argument: #REF! under the rule of section 2.8.1; #VALUE! when it is a range of two references (even for the same cell); otherwise TRUE when the cell is empty, FALSE when it is not. When the argument is a value argument: its error when it evaluates to an error, otherwise FALSE.

Texts. Lengths and positions are counted in UTF-16 code units.

Function Arguments Result
LEN(t) text the length of t, a number
UPPER(t) text t in capitals (JavaScript toUpperCase())
LEFT(t, n) text, integer #VALUE! when n is negative; otherwise the first n code units of t, or all of t when it is shorter
RIGHT(t, n) text, integer #VALUE! when n is negative; otherwise the last n code units of t, or all of t when it is shorter
MID(t, s, n) text, integer, integer #VALUE! when s is below 1 or n is negative; otherwise at most n code units of t starting at position s (the first position is 1); the empty text when s is beyond the end
CONCAT(a, …) one or more, each a range or a value For a range: the value of each cell converted to text (an empty cell gives the empty text), in visiting order. For a value: converted to text. The result is all these texts in order.

Conditional aggregates.

COUNTIF(range, criterion) — exactly two arguments. SUMIF(range, criterion, sum_range) — exactly three arguments.

The steps are made in this order; the first step that gives an error ends the function:

  1. If range is not a range argument: #VALUE!. For SUMIF, if sum_range is not a range argument: #VALUE!.
  2. If range gives #REF! under section 2.8.1: #REF!. For SUMIF, the same for sum_range.
  3. For SUMIF, if range and sum_range do not have the same number of rows and the same number of columns: #VALUE!.
  4. criterion is evaluated as an expression. An error is the result.
  5. The criterion is turned into an operator and an operand:
    • a number or a logical value: operator =, that value as operand;
    • blank: operator =, the empty text as operand;
    • a text that starts with >=, <=, <>, >, < or = (the longest match): that operator; the rest of the text gives the operand: a number when the rest is an entry number (section 2.2, without removing spaces), a logical value when the rest is TRUE or FALSE in any letter case, otherwise the rest as a text;
    • any other text: operator =, that text as operand.
  6. The cells of range are visited in order. For each cell:
    • an error cell is an error met: it is the result;
    • an empty cell never matches;
    • otherwise the cell matches as follows. Operator =: its value and the operand have the same type and are equal under section 2.7.6. Operator <>: it does not match =. Operators <, <=, >, >=: its value and the operand have the same type and the comparison of section 2.7.6 is TRUE.
    • COUNTIF counts the matching cells.
    • SUMIF looks at the cell at the same position in sum_range for each matching cell: an error cell is an error met; a number cell contributes; any other cell is ignored.
  7. The result is the count, or the contributions added in order starting from 0.

2.9 Circular references

  • The precedents of a cell that holds a valid formula are all the cells inside the grid named by a reference of the formula, and all the cells of the grid inside the rectangle of each of its ranges whose two corners are inside the grid. Every reference and range of the formula counts, wherever it stands, including in an argument that the evaluation does not reach (the branch of an IF that is not chosen, the second argument of IFERROR).
  • Any other cell (empty, number, text, logical, formula that is not valid) has no precedent.
  • A cell is circular when it can be reached from itself by following precedents one or more times. A formula that refers to its own cell is circular.
  • The value of a circular cell is #CYCLE!, whatever its formula.
  • A cell that is not circular is evaluated normally. When it refers to a circular cell, it reads the error #CYCLE!, which follows the rules of every error: it propagates, and IFERROR and ISERROR can catch it.

Example: A1 holds =B1+1, B1 holds =A1+1, C1 holds =A1+1, D1 holds =IFERROR(A1,5), E1 holds =IF(FALSE,E1,1). A1, B1 and E1 are circular and show #CYCLE!. C1 is not circular and shows #CYCLE!. D1 is not circular and shows 5.

2.10 Rewriting references

Sections 2.10.1 and 2.10.2 apply to every valid formula of the sheet when a row or a column is inserted or deleted. Section 2.10.3 applies to the valid formulas that are pasted. Formulas that are not valid, and contents that are not formulas, are never rewritten.

In the three sections:

  • $ signs are kept on the part they belong to.
  • A reference outside the grid as it was typed (for example Z9 or A40) is left unchanged, and a range with such a corner is left unchanged.
  • A reference outside a range that has to be removed is replaced by the token #REF!. A range that has to be removed is replaced, as a whole, by the token #REF!.
  • The rewritten formula is stored in canonical form (section 2.6.4).

2.10.1 Insertion

A row inserted at row r (the cells of rows r to 11 move down by one row, FR-STR-01):

  • Reference outside a range, of row n: unchanged when n < r; row n + 1 when n ≥ r; removed when n + 1 is 13.
  • Range of rows t to b (t ≤ b): both are moved by the rule above, giving t' and b'. Removed when t' is 13. Otherwise b' is limited to 12.

$ signs do not prevent the move. The rule for a column inserted at column c is the same with columns, H being the limit.

Examples, for a row inserted at row 3: =A2+A3 becomes =A2+A4; =$A$12 becomes =#REF!; =SUM(A1:A12) stays =SUM(A1:A12); =SUM(A3:B12) becomes =SUM(A4:B12); =SUM(A12:B12) becomes =SUM(#REF!).

2.10.2 Deletion

Row r deleted (the cells of rows r + 1 to 12 move up by one row, FR-STR-02):

  • Reference outside a range, of row n: unchanged when n < r; removed when n = r; row n - 1 when n > r.
  • Range of rows t to b (t ≤ b): unchanged when r > b; rows t - 1 to b - 1 when r < t; when t ≤ r ≤ b: removed when t = b, otherwise rows t to b - 1.

The rule for a deleted column is the same with columns.

Examples, for row 3 deleted: =A2+A4 becomes =A2+A3; =A3*2 becomes =#REF!*2; =SUM(A1:A5) becomes =SUM(A1:A4); =SUM(A3:B3) becomes =SUM(#REF!); =SUM(A3:A4) becomes =SUM(A3:A3).

2.10.3 Paste adjustment

A formula copied from a source cell and pasted into a destination cell is adjusted by the offset between the two cells: dc columns and dr rows (destination minus source).

  • In each reference, inside or outside a range: a column part without $ moves by dc columns; a row part without $ moves by dr rows. Parts with $ do not move.
  • A reference outside a range that ends outside the grid is removed. A range with one corner at least that ends outside the grid is removed.
  • A range is normalized again after the move (section 2.6.4), since its corners may have moved differently.

Examples, for a formula copied from B2 and pasted into D5 (dc = 2, dr = 3): =A1+$A1+A$1+$A$1 becomes =C4+$A4+C$1+$A$1; =SUM(A1:$B2) becomes =SUM($B4:C5); =G1 becomes =#REF!; =SUM(A1:G1) becomes =SUM(#REF!). For a formula copied from B2 and pasted into A1: =A1 becomes =#REF!.
