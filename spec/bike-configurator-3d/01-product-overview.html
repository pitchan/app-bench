1. Product overview

1.1 Purpose

Atelier lets a customer configure a made-to-measure bicycle on one page: enter their height, choose a frame size, wheels, drivetrain, color and accessories, set a quantity, apply a promo code, see the price and the delivery date update immediately, and place the order.

1.2 Scope

In scope:

  • Rider height and frame size recommendation.
  • Option choices with compatibility rules and automatic adjustments.
  • A live price summary with quantity discount, one promo code, shipping and VAT.
  • An estimated delivery date counted in workshop business days.
  • A live 3D bike preview that the customer turns with the pointer or the keyboard.
  • An order confirmation shown on the page.
  • A light and a dark theme, following the operating system preference.

Out of scope:

  • Payment, accounts, addresses, servers, e-mails.
  • Persistence: a reload starts a new configuration.
  • Currencies other than the euro. Every price includes VAT.
  • Any control not described in this specification (no theme switch, no reset button other than the one of FR-ORD-05).

1.3 User

One customer, on a desktop or a phone browser, using mouse, touch or keyboard.

1.4 Operating environment

  • A current version of Chromium.
  • The page is opened directly from the file system or from any static file server.
  • "Today" is the browser's current local date. The time of day is never used.
  • Viewport widths from 360 px to 1920 px.

1.5 Design and implementation constraints

  • One file named index.html. All HTML, CSS, JavaScript and SVG are inline. See NFR-PKG-01.
  • No library, framework, font or image loaded from the network. See NFR-NET-01.
  • No alert, confirm or prompt. See NFR-DLG-01.
  • The data-testid values, accessible names, texts and tokens of files 03 and 04 are part of the interface and shall be used exactly as written.

1.6 Assumptions

  • The page title and the page's visible brand title are set by the instructions that accompany this specification, not by this document.
