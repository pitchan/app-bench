3.2 Element identifiers

Each element below shall carry the attribute data-testid with exactly the given value, unique in the page.

Presence:

  • Permanent: present and visible while the configurator is shown (not during the confirmation).
  • Conditional: visible only in the situation the requirements describe; otherwise absent or not visible.

"Visible" and "not visible" have the meanings of README, section 2.5.

Option cards

One card per option of section 2.2 of the catalog, with data-testid card-<group>-<option id>, where <group> is frame, wheels, drivetrain, color or accessory.

Examples: card-frame-XL, card-wheels-275, card-drivetrain-pro, card-color-glacier, card-accessory-rack.

Each card is a <label> element that contains:

Inside the card Element Content Presence
the input <input type="radio"> for frame, wheels, drivetrain, color; <input type="checkbox"> for accessories. Radios of one group share one name. Accessible name exactly the catalog accessible name, e.g. Frame M (not the whole card text) Permanent
[data-role="name"] any The catalog accessible name Permanent
[data-role="price"] any FR-OPT-02 Permanent
[data-role="check"] any A check mark Conditional: visible only while the option is selected
[data-role="reason"] any MSG-04 or MSG-05 Conditional: visible only while the option is disabled
[data-role="badge"] any, frame cards only Text Recommended Conditional: FR-FIT-06
[data-role="swatch"] any, color cards only — Permanent

The input may be visually hidden; it shall stay focusable and operable with the keyboard.

3.3 Message catalog

"Text" is the element's text content with leading and trailing whitespace removed. It shall equal the message exactly. Parameters in braces are replaced as stated.

ID Text
MSG-01 Enter a height between 150 and 200 cm.
MSG-02 Recommended frame: {size} — {size} is S, M, L or XL
MSG-03 Frame {selected} is {n} sizes {direction} than recommended. — {selected} is the selected frame (S, M, L or XL), {n} is the size gap (2 or 3), {direction} is larger or smaller
MSG-04 Not available with frame S
MSG-05 Out of stock
MSG-06 Included with Pro
