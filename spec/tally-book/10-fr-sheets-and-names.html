10. Functional requirements — Sheets and defined names

10.1 Sheets

The rules on sheet names are in 02, section 2.12. The sheet controls are in sheet-bar (03, section 3.2). Adding, renaming and deleting a sheet are steps of the history (FR-HIS-05); switching sheets is not.

FR-SHT-01 Sheet tabs

  • Statement: The system shall show, inside sheet-tabs, one sheet-tab-<n> per sheet of the workbook, numbered from 1 in the order of the sheets, each showing the name of its sheet and nothing else, with aria-selected="true" on the tab of the active sheet and aria-selected="false" on the others. The system shall keep the tabs up to date after every change of the sheets or of the active sheet. On a new workbook there is one sheet, named Sheet1, and it is active.
  • Rationale: The user sees which sheets exist and which one the grid shows.
  • Verification: Test
  • Acceptance criteria:
Scenario: New workbook
  When the page loads
  Then there is 1 sheet tab
  And sheet-tab-1 reads "Sheet1"
  And sheet-tab-1 has aria-selected "true"
  And sheet-name-input has the value "Sheet1"
  And add-sheet is enabled
  And delete-sheet is disabled
  And sheet-message is not visible

FR-SHT-02 Adding a sheet

  • Statement: When the user clicks add-sheet while the workbook has fewer than five sheets, the system shall add a sheet after the last one, with the default name of 02, section 2.12, every cell empty with the format general, and A1 as anchor and active cell, and shall make it the active sheet. While the workbook has five sheets, the system shall disable add-sheet.
  • Rationale: A workbook grows one sheet at a time, up to a fixed number.
  • Verification: Test
  • Acceptance criteria:
Scenario: Up to five sheets
  Given the user enters "1" in C3
  When the user clicks button add-sheet
  Then there are 2 sheet tabs
  And sheet-tab-2 reads "Sheet2"
  And sheet-tab-2 has aria-selected "true"
  And sheet-tab-1 has aria-selected "false"
  And the selection is "A1"
  And cell-C3 shows nothing
  And sheet-name-input has the value "Sheet2"
  When the user clicks button add-sheet 3 times
  Then there are 5 sheet tabs
  And sheet-tab-5 reads "Sheet5"
  And the active sheet is "Sheet5"
  And add-sheet is disabled

Scenario: Default names
  Given the user renames the sheet to "sheet2"
  When the user clicks button add-sheet
  And the user clicks button add-sheet
  Then sheet-tab-1 reads "sheet2"
  And sheet-tab-2 reads "Sheet1"
  And sheet-tab-3 reads "Sheet3"

In the second scenario the second sheet added cannot be Sheet2: the first sheet has that name, letter case ignored.

FR-SHT-03 Switching sheets

  • Statement: When the user clicks the tab of a sheet, the system shall make that sheet the active sheet: the grid shall show its cells, and name-box, formula-input, format-select, selection-summary, aria-selected and data-in-selection shall follow the anchor and the active cell of that sheet, which are those it had when it was last active. The system shall set sheet-name-input to the name of that sheet. Switching sheets shall change neither the contents, nor the formats, nor the selection of any sheet, nor the clipboard, and shall create no history step. Clicking the tab of the active sheet shall change nothing but the value of sheet-name-input, set again to its name.
  • Rationale: Each sheet is found again as the user left it.
  • Verification: Test
  • Acceptance criteria:
Scenario: Each sheet keeps its cells, its selection and its formats
  Given the user enters "1234.5" in A1
  And the user clicks cell A1
  And the user sets the format to "fixed2"
  And the user clicks cell C3
  And the user shift-clicks cell E5
  When the user clicks button add-sheet
  And the user enters "x" in B2
  And the user enters "1234.5" in A1
  And the user clicks cell D4
  And the user clicks sheet tab 1
  Then the selection is "C3:E5"
  And cell-A1 reads "1,234.50"
  And cell-B2 shows nothing
  And cell-E5 has data-in-selection "true"
  And sheet-name-input has the value "Sheet1"
  When the user clicks sheet tab 2
  Then the selection is "D4"
  And cell-A1 reads "1234.5"
  And cell-B2 reads "x"
  And cell-D4 has aria-selected "true"
  And cell-E5 has data-in-selection "false"

Scenario: Switching is not a step
  Given the user clicks button add-sheet
  And the user clicks sheet tab 1
  When the user clicks button undo-button
  Then there is 1 sheet tab
  And undo-button is disabled

FR-SHT-04 Renaming a sheet

  • Statement: When the user clicks rename-sheet while the value of sheet-name-input is a valid sheet name (02, section 2.12) that no other sheet has, the system shall give that name, exactly as typed, to the active sheet, show it on its tab, and rewrite the formulas as FR-SHT-07 states. The name of the active sheet itself is not "another sheet": a renaming that changes only the letter case of the name is accepted. If the value is exactly the current name of the active sheet, then the system shall change nothing and create no history step. Pressing Enter in sheet-name-input shall start no action, and shall neither reload the page nor navigate.
  • Rationale: A sheet is called by what it holds.
  • Verification: Test
  • Acceptance criteria:
Scenario: New name, same name, other letter case
  When the user renames the sheet to "Budget 2024"
  Then sheet-tab-1 reads "Budget 2024"
  And sheet-name-input has the value "Budget 2024"
  And sheet-message is not visible
  When the user renames the sheet to "Budget 2024"
  And the user renames the sheet to "BUDGET 2024"
  Then sheet-tab-1 reads "BUDGET 2024"
  And sheet-message is not visible
  When the user clicks button undo-button
  Then sheet-tab-1 reads "Budget 2024"
  When the user clicks button undo-button
  Then sheet-tab-1 reads "Sheet1"
  And sheet-name-input has the value "Sheet1"
  And undo-button is disabled

FR-SHT-05 Sheet name rules

  • Statement: When the user clicks rename-sheet, the system shall check the value of sheet-name-input in this order. (1) If it is not a valid sheet name under rules 1 to 3 of 02, section 2.12, then the system shall change nothing in the workbook and show TXT-02 in sheet-message. (2) Otherwise, if another sheet has the same name, letter case ignored, then the system shall change nothing in the workbook and show TXT-03 in sheet-message. In both cases sheet-name-input shall keep the value typed and no history step shall be created. The value is taken as typed: spaces are not removed. sheet-message follows 03, section 3.5: the next click on add-sheet, rename-sheet or delete-sheet removes its text.
  • Rationale: Every sheet name can be written in a formula, and names one sheet only.

FR-SHT-06 Deleting a sheet

  • Statement: When the user clicks delete-sheet while the workbook has more than one sheet, the system shall remove the active sheet with its cells, its formats and its selection, and shall make active the sheet that takes its position in the order, or the last sheet when the deleted sheet was the last one. The other sheets keep their order, their contents and their selections. The formulas and the defined names that pointed to the deleted sheet change as FR-SHT-08 and FR-NAM-08 state. While the workbook has one sheet, the system shall disable delete-sheet.
  • Rationale: A sheet that is no longer needed is removed, and the workbook always keeps one.
  • Verification: Test
  • Acceptance criteria:
Scenario: Middle sheet, then last sheet
  Given the user enters "one" in A1
  And the user clicks button add-sheet
  And the user enters "two" in A1
  And the user clicks button add-sheet

  And the user clicks sheet tab 2
  When the user clicks button delete-sheet
  Then there are 2 sheet tabs
  And sheet-tab-1 reads "Sheet1"

  And sheet-tab-2 has aria-selected "true"
  And cell-A1 reads "three"
  And the selection is "B2"
  When the user clicks button delete-sheet
  Then there is 1 sheet tab
  And the active sheet is "Sheet1"
  And cell-A1 reads "one"
  And delete-sheet is disabled
  When the user clicks button undo-button
  Then there are 2 sheet tabs
  And the active sheet is "Sheet3"
  And cell-A1 reads "three"

FR-SHT-07 Formulas after a renaming

  • Statement: When a sheet is renamed, the system shall replace, in every valid formula of every sheet, each sheet prefix that names that sheet under its old name, letter case ignored, by the prefix of the new name, quoted when the new name needs it (02, sections 2.6.4 and 2.10.4), so that every formula keeps its value. The system shall change nothing else: not the formulas that are not valid, not the texts, not the prefixes that named no sheet before the renaming, not the clipboard.
  • Rationale: Renaming a sheet breaks no formula.
  • Verification: Test
  • Acceptance criteria:
Scenario: Prefixes follow the sheet
  Given the user enters "=sheet2!A1*2" in B1
  And the user enters "=Data!A1" in B2
  And the user clicks button add-sheet
  And the user enters "4" in A1
  And the user enters "=A1+Sheet2!A1" in C1
  And the user clicks sheet tab 1
  And the user enters "=Sheet2!A1+SUM(Sheet2!A1:B2)" in B3
  And the user enters "'=Sheet2!A1" in B4
  And the user enters "=Sheet2!A1+" in B5
  When the user clicks sheet tab 2
  And the user renames the sheet to "Q1 data"
  Then the raw content of C1 is "=A1+'Q1 data'!A1"
  And cell-C1 reads "8"
  When the user clicks sheet tab 1
  Then the raw content of B1 is "='Q1 data'!A1*2"
  And cell-B1 reads "8"
  And the raw content of B2 is "=Data!A1"
  And cell-B2 reads "#REF!"
  And the raw content of B3 is "='Q1 data'!A1+SUM('Q1 data'!A1:B2)"
  And cell-B3 reads "8"
  And the raw content of B4 is "'=Sheet2!A1"
  And the raw content of B5 is "=Sheet2!A1+"
  When the user clicks sheet tab 2
  And the user renames the sheet to "Data"
  And the user clicks sheet tab 1
  Then the raw content of B1 is "=Data!A1*2"
  And the raw content of B2 is "=Data!A1"
  And cell-B2 reads "4"

In this scenario B1 was committed before Sheet2 existed and is stored =sheet2!A1*2; its prefix names Sheet2, so the renaming rewrites it. B2 named no sheet until the second renaming; it is never rewritten, and it reads 4 once a sheet is named Data.

FR-SHT-08 Formulas after a sheet deletion

  • Statement: When a sheet is deleted, the system shall replace, in every valid formula of the remaining sheets, each reference and each range whose sheet prefix names the deleted sheet by the token #REF!, prefix included (02, section 2.10.5), and shall store the formula in canonical form. The system shall change nothing else. A sheet added later with the same name shall not bring these references back.
  • Rationale: A formula that lost its sheet says so, for good.
  • Verification: Test
  • Acceptance criteria:
Scenario: References to a deleted sheet
  Given the user clicks button add-sheet
  And the user enters "4" in A1
  And the user clicks sheet tab 1
  And the user enters "=Sheet2!A1+SUM(Sheet2!A1:B2)+A1" in B1
  And the user enters "=IFERROR(sheet2!$A$1,""gone"")" in B2
  And the user enters "'Sheet2!A1" in B3
  When the user clicks sheet tab 2
  And the user clicks button delete-sheet
  Then the active sheet is "Sheet1"
  And the raw content of B1 is "=#REF!+SUM(#REF!)+A1"
  And cell-B1 reads "#REF!"
  And the raw content of B2 is "=IFERROR(#REF!,""gone"")"
  And cell-B2 reads "gone"
  And the raw content of B3 is "'Sheet2!A1"
  When the user clicks button add-sheet
  And the user enters "4" in A1
  And the user clicks sheet tab 1
  Then sheet-tab-2 reads "Sheet2"
  And cell-B1 reads "#REF!"
  When the user clicks button undo-button 3 times
  Then the active sheet is "Sheet2"
  And cell-A1 reads "4"
  When the user clicks sheet tab 1
  Then the raw content of B1 is "=Sheet2!A1+SUM(Sheet2!A1:B2)+A1"
  And cell-B1 reads "8"

In this scenario the three undos take back the commit of 4 in the new sheet, the adding of that sheet and the deletion of the first Sheet2.

10.2 Defined names

The rules on defined names are in 02, section 2.13. The name controls are in names-panel (03, section 3.2). Defining and deleting a name are steps of the history (FR-HIS-05). The defined names belong to the workbook: they are the same whatever the active sheet.

FR-NAM-01 Defining a name

  • Statement: When the user clicks define-name while the value of name-input passes the checks of FR-NAM-02, the system shall add a defined name to the workbook: its name is the value of name-input as typed; its target is the selection of the active sheet, a cell target when the selection is one cell and a range target otherwise. The system shall then empty name-input, and shall evaluate again the formulas that use that name. The selection shall not change. Pressing Enter in name-input shall start no action, and shall neither reload the page nor navigate.
  • Rationale: A block of cells gets a name that formulas can use from any sheet.
  • Verification: Test
  • Acceptance criteria:

In these three cases the system shall change nothing in the workbook, keep the value of name-input and create no history step. name-message follows 03, section 3.5.

FR-NAM-05 Names in formulas

The canonical form shall write the name in capitals. A name followed by ( is a function call, and a name after a sheet prefix makes the formula not valid.

FR-NAM-06 Names as range arguments

  • Statement: The system shall treat an argument that consists of exactly one name as a range argument (02, section 2.8.1): where a function takes a range, the cells of the target of the defined name are used, in the sheet of the target, in visiting order. If the name is not a defined name, then the range gives #NAME?; if its target was removed, #REF!. ISBLANK of a name with a cell target tells whether that cell is empty, and gives #VALUE! for a name with a range target. The cells of the target of a defined name are precedents of the formulas that use it (02, section 2.9): defining or deleting a name can create or break a cycle.
  • Rationale: A named block is used wherever a range is, with the same rules.
  • Verification: Test

FR-NAM-07 Names after insertions and deletions

  • Statement: When a row or a column is inserted or deleted in the sheet of the target of a defined name, the system shall move that target as 02, sections 2.10.1 and 2.10.2 state, a cell target as a reference outside a range and a range target as a range: it follows its cells, grows or shrinks with an insertion or a deletion inside it, is cut at the edge of the grid, and becomes removed when the rule says "removed". A removed target shall stay removed, with the target text #REF!. An insertion or a deletion in another sheet shall not change the target. The raw contents of the formulas that use the name shall not change.
  • Rationale: A name keeps standing for the same data when the data moves.
  • Verification: Test

FR-NAM-08 Names and sheets

  • Statement: When the sheet of the target of a defined name is renamed, the system shall keep the target on that sheet and show its new name in the target text. When that sheet is deleted, the target shall become removed: the name stays defined, its target text is #REF!, and the formulas that use it read #REF!. A sheet added or renamed later with the name of the deleted sheet shall not bring the target back.
  • Rationale: A name follows its sheet, and does not jump to another one.
  • Verification: Test
  • Acceptance criteria:
Scenario: Renamed, then deleted
  Given the user clicks button add-sheet

  And the user clicks cell A1

  And the user clicks sheet tab 1
  And the user enters "=Top+1" in B1

  When the user clicks button add-sheet
  And the user renames the sheet to "Q1 data"

FR-NAM-09 Names and moved contents

  • Statement: The system shall change the target of a defined name only as FR-NAM-07 and FR-NAM-08 state. Pasting, cutting, clearing, sorting, filling, replacing and importing change the contents of cells and never a target: the name stands for the cells of its rectangle, whatever they hold afterwards. When a formula is pasted or filled, the system shall leave its name tokens unchanged (02, section 2.10.3).
  • Rationale: A name is an address with a label; moving values does not move the label.
  • Verification: Test
  • Acceptance criteria:
